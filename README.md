# Awesome Ads

[![CI](https://github.com/TMHSDigital/Awesome-Ads/actions/workflows/ci.yml/badge.svg)](https://github.com/TMHSDigital/Awesome-Ads/actions/workflows/ci.yml)

**A practical advertising playbook for small businesses.**

Awesome Ads is an open reference for planning, launching, and refining campaigns across digital and traditional channels. Each guide stands on its own: read cover to cover or jump straight to the channel you need.

The GitHub Pages sidebar, home page, and section indexes are generated at build time from the markdown files under `docs/channels/`, `docs/resources/`, `docs/ad-templates/`, and `docs/meta/`. Add a file with an H1 and it appears on the next deploy.

## For contributors and agents

Human contributors should start with [CONTRIBUTING.md](CONTRIBUTING.md) and [Community Guidelines](docs/meta/COMMUNITY_GUIDELINES.md). Automated agents should read [AGENTS.md](AGENTS.md) before editing this repository.
